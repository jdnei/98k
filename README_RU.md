Полностью выделенные линии IEPL: Используется сквозная изоляция по выделенным линиям финансового уровня без прохождения через публичный интернет, что значительно снижает потерю пакетов и задержку и помогает эффективнее справляться с сетевыми колебаниями.

Высокодоступное аварийное резервирование: Помимо основных выделенных линий предоставляются 3 качественных прямых узла с коэффициентом 0.5x в качестве резервных маршрутов, помогая сохранять сервис «всегда онлайн» даже в особые периоды.
Расчёт по коэффициенту 1x: За исключением резервных узлов, все основные узлы тарифицируются с коэффициентом 1x, что делает расход трафика прозрачным.
